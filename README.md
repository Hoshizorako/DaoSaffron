# DaoSaffron

Syncs metadata across multiple blockchain networks for developers building decentralized applications and services.

DaoSaffron is built to be simple and practical, focusing on doing one thing well.

**Why DaoSaffron?**

- Syncs metadata across multiple blockchain
- networks for developers building decentralized
- applications and services

## Technology Stack

- typescript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoSaffron.git`
2. `cd DaoSaffron`
3. Install in editable mode: `pip install -e .`

## Configuration

DaoSaffron is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
